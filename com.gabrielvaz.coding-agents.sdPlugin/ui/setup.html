Connecting adds hooks to the agent's settings file (a backup is kept next to it). Start a new agent session afterwards. Codex asks you to review new hooks once: open Codex and run /hooks.

Behavior

Claude Code shows its own prompt at the same time, so you can answer on the deck or in the terminal, whichever comes first. Codex asks in the terminal only after this wait. A timeout never decides anything, and pressing the session key opens the window and hands the question to the terminal at once.
