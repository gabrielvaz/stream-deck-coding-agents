Every state at a glance

Working keys always move, and each state has its own motion and mark, so you can read the deck from across the room without relying on colour. Switch the theme above and these change too.

Made for running many agents at once

The keys sort themselves: sessions waiting for you first, then working ones, then the ones that just finished. They hold still for a moment after you press one, so nothing moves under your finger.

✔

Approve from the deck

Claude Code and Codex permission requests show the exact command on the key. Hold it to allow, or use the Allow and Deny keys. The terminal prompt still works, and whichever answers first wins.

Jump to the window

A press brings that session's terminal or editor to the front: the right Windows Terminal tab, VS Code, Terminal.app or iTerm2 tab, or the herdr pane.

⚡

One click per agent

Press Connect in the key settings. The plugin adds its hooks (with a backup) and removes only its own entries when you disconnect. It uses Stream Deck's built-in Node.js, so there's nothing else to install.

Everywhere you code

Windows, macOS, agents inside WSL, and servers you reach over SSH. A remote machine needs only curl and python3.

24+ agents through herdr

Private by design

A local endpoint on 127.0.0.1 with a token only your account can read. No account, no analytics. Only an Agent Limits key asks Anthropic or Google for your own usage.

Know how much is left

An Agent Limits key shows how much of your usage is left before you hit the wall, and when it comes back. Place one key per agent.

  • Claude Code and Codex: the 5-hour and weekly windows, each with a bar and the time until it resets.
  • Antigravity: the quota of each model, the most used first.
  • The bar turns orange at 25 % left and red at 10 %. Press the key to refresh.

Set up in a minute

Requires the Stream Deck app 7.1 or later on Windows 10+ or macOS 12+.

Install

Double-click com.gabrielvaz.coding-agents.streamDeckPlugin from the latest release, or get it from the Elgato Marketplace.

Place keys

From the Coding Agents category, drag an Agents Overview key and as many Agent Session keys as you like. Add Allow and Deny if you want them.

Connect

Select a key, then press Connect next to each agent in its settings. Start a new agent session and watch it light up.

Questions

Do I need Node.js, a server or a terminal command?

No. The plugin runs its own local endpoint and the hooks use the Node.js runtime that ships with Stream Deck.

What happens if Stream Deck isn't running?

The hooks answer neutrally and exit in milliseconds, so your agents never wait. A permission request the deck didn't answer simply shows its normal prompt.

Can a key approve something by accident?

Approving needs a deliberate hold (a green bar fills) or the dedicated Allow key, and the key shows the exact command first. A timeout never decides anything.

Which Stream Decks are supported?

All keypad models: Original, MK.2, XL, Mini, Neo, Stream Deck +, Studio, plus the mobile and virtual Stream Deck. Text gets larger automatically on 72 px keys.

Does it work with Claude Code in WSL or on a remote server?

Yes. WSL distros get their own Connect rows on Windows. For a server, the settings show an ssh -R command and a one-line setup to run there.

Is my data sent anywhere?

No. Session data stays on your computer. The one exception is the Agent Limits key: it asks Anthropic (Claude Code) or Google (Antigravity) for your own usage, with the sign-in the agent already keeps. See the privacy policy.
